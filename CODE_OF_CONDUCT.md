# Code of Conduct

Vaani X is a project for Telugu developers, and for anyone who wants Telugu speech to be self-hostable. Be the kind of community that makes people want to contribute.

## Our standards

- Be respectful and kind, especially to new contributors and to people writing in Telugu or in English as a second language.
- Assume good intent. Criticise the code and the claim, not the person.
- No harassment, hate speech, or unwelcome personal attention, in issues, pull requests, or discussions.
- Keep it honest: do not post fake benchmarks, fake testimonials, or claims about accuracy, cost, or users that you cannot show the measurement for.

## Scope

This applies in the repository, in issues and pull requests, and in any project space (including a Hugging Face Space or demo) run by the maintainers.

## Enforcement

If you see behaviour that breaks this code, report it to the maintainers. A report is treated confidentially. Maintainers may warn, temporarily restrict, or permanently remove a participant, depending on severity. Maintainers who break the code are held to the same standard.

This is a short code of conduct for a small project. If the community grows, adopt a fuller one (for example the Contributor Covenant) and link it here.
