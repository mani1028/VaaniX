Project

This page is the project overview. The same process serves the API and this site.

What it is

A single Python process named telugu-speech. Other apps call it for Telugu text to speech and speech to text. There is no separate cloud account.

Voices and language

Srinivas and Sravani. Language code te only. Style is conversational. Text is limited to 2,000 characters.

Memory

One request keeps one speech engine, about 260–470 MB. Overlapping calls grow up to 8 engines, then drop back to one. Recognition is one shared model, about 350–540 MB when loaded.

Who it is for

Your own services sharing one host. Put TLS and a rate limit on a proxy. Set TELUGU_SPEECH_AUTH=required before anyone else can reach the port.

What it does not do

It does not translate. It does not speak other languages. It is not a measured match for Sarvam. Voice naturalness against other services was not scored.

Where the code lives

src/telugu_speech is the package. Weights stay in models/telugu-asr-micro and lite/models/hima-tts-nano-te. The full write-up is the repository README.

Install

Clone the repository, then install telugu-speech. Srinivas and Sravani are already in that tree. Everything runs on your computer.

1. Clone

One repository. There is no second repo for the voices.

2. Install the package

Use Python 3.11, inside that clone.

python -m pip install -e ".[host]"

3. Run

On your own computer, no key is needed.

TELUGU_SPEECH_AUTH=local_open telugu-api

Then open http://127.0.0.1:8000/.

Two ways to use it

Pick one. You do not need both. A key is only a password for the server, not a license for the voices.

From another app

Start the server with step 3. Your app sends text or a WAV, and reads the reply. No internet service is called.

Make it speak. Send Telugu text. The reply includes audio_url. Open that address to get the WAV.

curl -s -H "Content-Type: application/json" \
  -d '{"text":"నమస్కారం","language":"te","voice":"telugu_srinivas","format":"wav"}' \
  http://127.0.0.1:8000/api/v1/tts/generate

Make it listen. Send a normal WAV file. The reply field text is the transcript. Place the recognizer in models/telugu-asr-micro. Those weights are separate from the telugu-speech package.

curl -s -F "audio=@clip.wav;type=audio/wav" \
  http://127.0.0.1:8000/api/v1/asr/transcribe

If other computers can open this address, choose a password and start with TELUGU_SPEECH_AUTH=required and TELUGU_API_KEYS=your-password. Each request then sends Authorization: Bearer your-password.

From your own Python code

Do not start a server. There is no key. Import telugu-speech and call it from your program.

Make it speak. This writes speech.wav for the voice you picked.

from pathlib import Path
from telugu_speech.tts.voices import backend_for_voice

engine = backend_for_voice("telugu_srinivas")
engine.synthesize("నమస్కారం", None, "", Path("speech.wav"))

Make it listen. This prints the transcript. Point it at models/telugu-asr-micro after you add that folder next to the package.

from pathlib import Path
from telugu_speech.asr.infer import FasterWhisperBackend

engine = FasterWhisperBackend("models/telugu-asr-micro")
print(engine.transcribe(Path("clip.wav")))
